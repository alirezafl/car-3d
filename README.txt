# Car 3D Viewer

این پوشه یک Viewer آماده برای مدل GLB خودرو است.

فایل‌ها:
- index.html
- car.glb

برای انتشار عمومی، هر دو فایل را روی یک هاست وب قرار دهید و لینک index.html را در WhatsApp Channel بگذارید.

نکته: index.html برای اجرای مدل از model-viewer استفاده می‌کند و کتابخانه را از CDN رسمی Google AJAX دریافت می‌کند؛ بنابراین مرورگر هنگام اجرا به اینترنت نیاز دارد.
